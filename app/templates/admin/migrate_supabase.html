Executar Migração para o Supabase

Cole a URI de conexão direta do PostgreSQL do seu projeto Supabase (ou deixe em branco caso já tenha definido SUPABASE_DB_URL no ambiente).

O que este assistente fará automaticamente:
  • Criará as tabelas do Master DB no schema public do Supabase.
  • Copiará seus segmentos de mercado, usuários administradores e contas de clientes.
  • Criará um schema dedicado tenant_{username} no Supabase para cada empresa.
  • Copiará todos os pedidos, clientes, produtos e lançamentos financeiros para o schema correspondente.
  • Atualizará o cadastro das empresas para operarem via schema permanente no Supabase.
💡

Como obter sua URL no Supabase

1. Acesse o Painel do Supabase Entre em seu projeto no Supabase e clique na engrenagem Project Settings na barra lateral esquerda.
2. Abra a aba Database Role a página até a seção Connection String e selecione a aba URI.
3. Copie a Connection String A URL terá o seguinte formato: postgresql://postgres:[SUA_SENHA]@db.[REF].supabase.co:5432/postgres Lembre-se de substituir [SUA_SENHA] pela senha definida na criação do projeto.
4. No Render No dashboard do Render, abra seu serviço bling-bi, vá em Environment e defina a variável:
SUPABASE_DB_URL = [sua_url_completa]
